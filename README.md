# factpalmera

Tablero de márgenes de Palmera (HTML de un solo archivo).

- `tablero-palmera.html`: vista Márgenes (costo del producto, facturación total y margen retail por cadena y SKU), calculada desde la hoja FACTURA de `Facturación_Palmera_SEP.xlsx`.
- La vista Ventas (hoja CONSOLIDADO) está oculta; se reactiva con `SHOW_VENTAS=true` en el script.
